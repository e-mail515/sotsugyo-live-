# 申請済みバンド

卒業ライブに申請されたバンドを、スマホで見やすい一覧ページに自動で表示します。
申請した人が自分の回答に間違いがないかを確認したり、どんなバンドが申請されているかをみんなで見たりするためのページです。

- `gas/Code.gs`：回答スプレッドシートから「表示してよい列だけ」をJSONで返すAPI
- `docs/`：一覧サイト（GitHub Pages でそのまま公開できます）

メールアドレス・タイムスタンプ・演奏曲・対バン・自由記入欄は、GASの段階で取り除いています。サイトには届きません。

---

## 1. GAS（データAPI）を用意する

1. 回答スプレッドシートを開き、「拡張機能 → Apps Script」を選ぶ
   - 「現在、ファイルを開くことができません」と出る場合は、ブラウザで複数の Google アカウントにログインしていることが原因です。
     シークレットウィンドウを開き、スプレッドシートの持ち主のアカウントだけでログインしてから開き直してください。
2. `gas/Code.gs` の中身を丸ごと貼り付けて保存する（💾）
3. 上の関数選択で `testOutput` を選んで「実行」する
   - 初回は「承認が必要です」と出るので、自分のアカウントで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細 → 〜に移動」）
   - 「実行ログ」に JSON が出て、メールアドレスが含まれていないことを確認する
4. 右上の「デプロイ → 新しいデプロイ」を開く
   - 種類の選択（⚙）→「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーする
6. そのURLをブラウザで開き、JSON が表示されることを確認する

### GAS のコードを書き換えたとき

保存しただけでは公開中のURLに反映されません。
「デプロイ → デプロイを管理 → ✏（編集）→ バージョン：**新バージョン** → デプロイ」を行ってください。
「新しいデプロイ」を作るとURLが変わるので注意してください。

### フォームの質問を変えたとき

`gas/Code.gs` の先頭にある `COLUMNS` で、ヘッダー名（質問文）と出力キーを対応させています。
質問文を変えたときは、ここも同じ文言に直してから新バージョンでデプロイしてください。
`COLUMNS` に書いていない列は出力されません。
「不可時間 [○○]」の形をした列は、自動で日付として扱います。

## 2. サイトに API の URL を設定する

`docs/index.html` のスクリプトの先頭を書き換えます。

```js
const API_URL = "https://script.google.com/macros/s/…/exec";
```

空欄のままにすると、80組分のダミーデータ（モック）で表示されます。見た目の確認に使えます。

## 3. GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（無料プランで Pages を使うなら Public）
2. このフォルダの中身をアップロードする（`docs/` フォルダごと）
   - ブラウザだけで行う場合は「Add file → Upload files」でフォルダをドラッグ＆ドロップ
3. リポジトリの「Settings → Pages」を開く
   - Source：**Deploy from a branch**
   - Branch：**main**、フォルダ：**/docs** →「Save」
4. 1〜2分ほどで `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開される

> ⚠ Public リポジトリにすると、ファイルの中身は誰でも見られます。
> 実在のメールアドレスなどをファイルに書かないでください。
> 表示されるバンド名とメンバー名も、URL を知っている人なら誰でも見られます。URL はサークル内だけで共有してください。

### サイトを更新したとき

Service Worker がページをキャッシュしているため、更新後に**1回目に開いたときは古い画面**が表示されます。
裏で新しい版を取得しているので、**もう一度開き直すと新しい画面**になります。
データ（バンド一覧）はこれとは関係なく、毎回最新のものを取得します。

## 使い方（閲覧する人向け）

- 申請されたバンドが、回答順に1バンド1カードで並びます
- **申請内容の確認**：検索欄にバンド名か自分の名前を入れると、そのバンドが不可時間まで開いた状態で表示されます
- メンバー名をタップすると、その人が出ている全バンドに絞り込みます
- 不可時間は、カード下の「不可時間 木3 金2…」をタップしても開けます
- フォームを送信してから一覧に出るまで、最大1〜2分かかります
- 開いている間は60秒ごとに自動で更新します。右上の ↻ を押すとすぐに更新します
- 一度開いた端末なら、圏外でも前回のデータが表示されます（画面上部に「オフライン表示中」と出ます）
- ホーム画面に追加すると、アプリのように開けます

## 動作確認チェックリスト

- [ ] `testOutput` のログと、ウェブアプリURLの JSON にメールアドレスが含まれていない
- [ ] スマホ幅で横スクロールが出ない
- [ ] Chrome DevTools の Network を「Slow 3G」にしても数秒で表示される
- [ ] 一度開いた後に「Offline」でリロードしても、前回のデータが表示される
